### AI & I by Every：为什么 Every 放弃个人 Agent、转向公司 Agent

一句话结论：个人 agent 浪潮还会再来一遍，但公司层面最终会收敛到"一家公司一个 agent"——这是 Every 用九个月时间和两个死掉的产品（全员 OpenClaw、一键 claw 平台 Plus One）换来的教训。

Dan Shipper（Every CEO）与 Willie Williams（Every 平台负责人、Every Agent 工程负责人）完整复盘：八个月前全员 OpenClaw 个人 agent 实验为何无疾而终——安全问题难做、维护成本高、不投入就会慢慢荒废；真正的价值其实是"看见别人怎么用 AI"。后来的 Plus One（RIP）想做成 claw 即服务平台，又发现 OpenClaw 这类高速迭代、vibe coded 的开源项目根本不适合当平台底座。转折点是意识到单一公司 agent 的复利：所有人使用即所有人贡献，agent 会逐渐长成这家公司的形状；而"记住哪个 agent 擅长什么"本身就是摩擦。对未来的判断：职场一侧会是 one agent per company——个人 agent 缺乏组织上下文、"得在场一年才能真正上手"；个人一侧（Dots、Muse、Instinct、Grok bots）个性化诉求巨大，大厂入场正解决安全与易用性，未来会出现 agent 版"影子组织架构图"。工程管理部分同样精彩：Williams 转回管理岗后 token 用量"断崖式下跌"——管理者的杠杆来自人而非 token；agent 值班（永不休假的 on-call）、异常检测、智能路由正把"线下管理工作"自动化。

金句："我们不会看到行业重演'每个员工配一个 agent 同事、公司规模直接翻倍'的混乱。"
