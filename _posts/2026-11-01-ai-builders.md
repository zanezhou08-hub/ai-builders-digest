## 🎙️ PODCASTS

### No Priors：Taking on ServiceNow: Coding Agents the Rest of Us — 对话 Serval 联合创始人兼 CEO Jake Stauch

Serval（非洲野猫之名）是一家用 coding agent 做企业自动化/服务管理、直接对标 ServiceNow 的公司。Jake Stauch 曾在 Verkada 卖了多年企业安防产品，他问 IT 团队的两个固定问题是"你在什么上面花钱最多"和"你最恨什么"——ServiceNow 两个榜单都名列前茅。本期聊透了一家成立两年半、从 20 人涨到 200 人的公司如何正面进攻企业软件的系统级巨头。

- **核心洞察：代码才是表达企业自动化的正确方式。** 拖拽式 workflow builder 对非技术用户太复杂、对技术用户又抽象得难受。过去的问题只是"没多少人能写代码"——AI 把这个前提推翻了，于是"人人可写代码 + 自动化应该用代码写"两件事咬合到了一起。创始时的赌注是 coding agent 在可验证领域会快速爬坡，早期靠喂大量示例 workflow 撑场面，后来模型好到"你很难给出一个它自动不了的流程"。

- **"为其余所有人服务的 coding agent"。** 早期企业 AI 采用集中在工程团队，因为代码审查流程让 19 岁实习生也能安全地构建强大的东西。Serval 把同样的安全结构（staging、审批环、审计轨迹）带给 IT 部门，再由 IT 带给 HR、财务、法务——毕竟大多数公司只有 IT 部门，没有软件工程部。

- **Serval 就是边界本身。** 大企业里流程、审批、政治无处不在，个人 agent 在企业权限体系下"连邮件都读不了几封"。他的判断反直觉：企业权限会越收越紧、走向真正的最小权限，而 Serval 靠"拥有权限例外的授予方式"（确定性审批工作流 + 工单 + 审计）反而越收紧越不可或缺。"我们不做 LLM，我们做的是护栏。智能变得更强只会让我们的产品更强大。"

- **正面进攻巨头。** 常规打法是做巨头之上的薄层（上限低）或者下沉市场（Rippling/HubSpot 路线），Serval 选择直接挑战："一切都在我们非常妄想级的计划之中"——两人创始时就列了所有巨头名单、圈掉 ServiceNow，说要做成史上最大的企业软件公司。Fox Corporation 全公司部署 Serval，主导迁移的员工被提名为全公司 MVP——"我们必须让客户相信，选 Serval 是你升职的方式，而不是你冒的险。"

- **关于 SaaSpocalypse。** 试图 vibe code 自建核心系统记录（system of record）的公司都发现企业软件建起来、养起来都贵得离谱，除非需求极度独特，否则 build vs buy 的老逻辑依然成立。真正的洗牌发生在长尾：几百个 SaaS 点解决方案和中间件会被核心平台吃掉，但 ERP/HRIS/ITSM/CRM 这些品类不会消失，只会换一代新在位者。

- **组织方式。** 没有 product 职能——产品决策权下放到工程师，绝大多数工程师每天至少上一个客户会、泡在客户 Slack 频道里，"像沉浸式学外语一样沉浸在客户思维里"；招人速度还要加快，因为"对工作的需求、竞争和野心都是无限的，每个员工比一年前能干得多，我们反而想要更多这样的人"。他最骄傲的一点是反复推翻自己深度投入过的东西："市场变了，客户变了，我们就彻底换一种做法。"

金句："Serval 是边界，Serval 是护栏。我们就是那个满是规则、审批、流程与政治的大企业能够安全、安心、规模化采用这些工具的方式。"
